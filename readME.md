# Архиватор 

**Метод сжатия: `Variable-length code`**

Суть метода *Код переменной длины* (`Variable-length code`), заключаетсся в составлении таблицы кодов, таким образом, что наиболее частые символы, записываются наиболее короткими по длине последовательностями. 


### Таблица кодирования

|Символ:Последовательность|Символ:Последовательность|
|---|---|
': 11|'e': 101|
't': 1001|'o': 10001|
'n': 10000|'a': 011|
's': 0101|'i': 01001|
'r': 01000|'h': 0011|
'd': 00101|'l': 001001|
'!': 001000|'u': 00011|
'c': 000101|'f': 000100|
'm': 000011|'p': 0000101|
'g': 0000100|'w': 0000011|
'b': 0000010|'y': 0000001|
'v': 00000001|'j': 000000001|
'k': 0000000001|'x': 00000000001|
'q': 000000000001|'z': 000000000000|

> Любой символ верхнего регистра кодируется `!` перед символом нижнего регистра, то есть `A = !a`

Особенность таблица заключается в использоваинии *Префиксоного кода*.

> Прекисный код &mdash; это тип кода, в котором ни одно кодовое слово не является префиксом другого.
>
>**ТО ЕСТЬ** любая последовательность может декодироваться лишь одним конкретным образом без использования спец.символов    

#### Пример сжатия
**Hello:** 
+ H = !h = 001000 + 0011 
+ e = 101
+ l = 001001
+ l = 001001
+ o = 10001

Далее группируем все биты в байты, а не в достающие группы добавляем нули -> 00100000 + 11101001 + 00100100 + 110001*00* = 4 *байта*.

И получается что *Hello: 4б*, а в случае *(ASCII) Hello: 6б*, и тогда процент сжатия ~30%
